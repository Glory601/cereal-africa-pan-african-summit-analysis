# Power BI Dashboard

## Overview

The Power BI dashboard was developed to monitor Cereal+ Africa Pan African Summit registration performance and provide a clear view of campaign results.

## Key Metrics

The dashboard tracks:

- Total registrations
- Registration target
- Target achievement
- Week 4 registrations
- Week 4 growth
- Registration channels
- Participant categories
- Geographic distribution
- Daily registration trends

## Key Findings

The final dashboard showed:

- **68 total registrations**
- **85% achievement of the 80-registration target**
- **22 registrations recorded in Week 4**
- **69% Week 4 growth**
- **37 registrations generated through WhatsApp**

## Business Value

The dashboard provides stakeholders with a centralized view of campaign performance and helps identify:

- Strong registration channels
- High-performing participant segments
- Geographic participation
- Changes in registration momentum
- Areas requiring additional outreach
