# Data

This folder contains information about the data used for the Cereal+ Africa Pan African Summit registration analysis.

## Data Source

Registration responses were collected and tracked using Google Sheets during the campaign.

## Data Used for Analysis

The analysis considered fields related to:

- Registration date
- Participant category
- Country
- Registration source
- Registration activity over time

## Privacy

The original registration dataset contains personally identifiable information such as participant names, email addresses, and phone numbers.

For privacy and security reasons, the raw participant-level dataset is **not included in this public repository**.

Only a privacy-safe screenshot showing the structure of the registration tracking sheet is included in the project screenshots.

## Data Preparation

The registration information was organized and reviewed before being used for analysis and Power BI visualization.

The prepared data supported analysis of:

- Registration performance
- Participant segments
- Acquisition channels
- Geographic distribution
- Registration trends
